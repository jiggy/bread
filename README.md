# A reusable licensing model

Start with [DOCTRINE.md](DOCTRINE.md), the single source for the core idea,
principles, vision, purpose, mission, north star, and decision hierarchy.

## Working materials

| File | Status and purpose |
| --- | --- |
| [DOCTRINE.md](DOCTRINE.md) | Governs the independent model's design and stewardship. |
| [LICENSE.md](LICENSE.md) | Non-operative Jig license proposal; starting material for extracting the reusable standard. |
| [PRICING.md](PRICING.md) | Proposed Jig pricing and explanation, not universal prices for every adopter. |
| [CONTRIBUTOR-AGREEMENT.md](CONTRIBUTOR-AGREEMENT.md) | Proposed Jig contribution permissions; adopting the model does not require this governance arrangement. |

Jig is the first intended adopter. An independent name and reusable legal text
remain to be developed. These drafts are not issued licenses, executed
agreements, or a live purchasing offer. Doctrine guides revisions; applicable
legal grants determine actual permissions.

The independent repository contains the current working materials. Its
operation and editing guidance are in [AGENTS.md](AGENTS.md).
